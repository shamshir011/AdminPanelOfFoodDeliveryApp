
# Food Delivery Admin App (Android)

A dedicated Admin Android application to manage the Food Delivery platform.
This app allows administrators to control restaurants, food items, categories, user orders, and view analytics in real-time.

---

## ✨ Features

* Admin authentication and secure access
* Manage restaurants
* Upload, update, and delete food items
* Create, edit, and delete food categories
* Manage user orders (view and update order status)
* Analytics dashboard to monitor app data and performance
* Real-time data synchronization using Firebase
* Upload images using Firebase Storage
* Efficient data handling for smooth admin operations

---

## Tech Stack

* **Language:** Kotlin
* **UI:** XML + RecyclerView
* **Backend:** Firebase Realtime Database
* **Authentication:** Firebase Auth
* **Storage:** Firebase Storage
